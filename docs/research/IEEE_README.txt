Indian Institute of Information Technology Dharwad

Compiled paper: IsoLab_Research_Paper.pdf (separate download)

OVERLEAF
Create a project by uploading the ZIP. Select IsoLab_IEEE.tex as the main
document and pdfLaTeX as the compiler. All required inputs are at the ZIP root:
  IsoLab_IEEE.tex
  comparison-derived.tex
  pilot-section.tex
  pilot-results.tex
  pilot-controls.tex
  ieee-architecture.pdf
  ieee-latency.pdf

  ieee-pilot-detection.pdf
  ieee-pilot-controls.pdf
The 22-entry bibliography is inline in IsoLab_IEEE.tex; BibTeX is not required.
IEEEtran and the referenced standard packages are available in a normal TeX setup.
Share the URL generated by your own Overleaf project for submission. This archive
is source code, not a hosted Overleaf project or a fabricated project link.

PAPER CONTENT
12 Letter pages in IEEE conference format; five vector figures and eleven tables.
Historical E1-E5 evidence remains distinct from the November matched pilot.
The pilot uses 160 runs and execution-level 40/30/30 train/validation/test splits.
Its baseline is an explicitly documented single-host 2024-inspired architecture
adaptation, not reproduction of the source's 411-feature distributed pipeline.
The full comparison includes unfavorable outcomes and competing-throughput cost.
Post-hoc paired-bootstrap sensitivity intervals are identified as exploratory.

LOCAL BUILD
The repository script scripts/build_research_paper.py regenerates plots/tables
and compiles with Tectonic or pdfLaTeX. It requires ReportLab, Matplotlib and the
recorded evidence. scripts/pilot_publication.py audits the completed pilot first.
scripts/check_research_paper.py verifies citations, links, embedded fonts, Letter
geometry and source figure/table counts. Pages are rendered for visual review.
A fresh Overleaf compilation needs only this ZIP.
